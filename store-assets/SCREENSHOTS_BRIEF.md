# Screenshots brief — 8 frames (real UI only)

Capture from the **live PWA** on a phone or Chrome device toolbar (portrait):  
https://leemcq.github.io/logosliving/

**Do not** mock fake UI, invent buttons, or edit in competitor branding. Crop status bars if needed; keep game chrome authentic.

Play Console typically wants **phone** screenshots (min 2; aim for 4–8). Use PNG or JPEG; avoid heavy compression artifacts.

## Capture script (in order)

| # | Frame | How to get it |
|---|--------|----------------|
| 1 | **Home / mode picker** | Fresh load showing Sing, Act, Explain (and other modes) clearly |
| 2 | **Sing mode — word card** | Start Sing; show an active round with a Bible word on screen (blur if you prefer not to spoil a pack) |
| 3 | **Act mode** | Same for Act — word + timer/controls visible |
| 4 | **Explain mode** | Same for Explain |
| 5 | **Championship** | Championship lobby or mid-round score feel |
| 6 | **Library** | Library browser with word list / packs visible |
| 7 | **Denomination packs** | Pack picker or unlock screen (no fake “paid” badges you don’t ship) |
| 8 | **Group play moment** | Teams/setup or pass-the-phone prompt that shows it’s a multiplayer room game |

## Tips

- Dark theme (`#0F0F1A`) — shoot in a lit room so screenshots aren’t pure black mush.
- One device width for consistency (e.g. Pixel-class 1080×2400 crop).
- Feature graphic is separate (`feature-graphic-1024x500.png`) — do not use a screenshot as the feature graphic.
- High-res icon: `icon-512.png` (already in this folder).
